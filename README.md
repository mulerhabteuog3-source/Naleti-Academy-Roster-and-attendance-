# Naleti Academy – Online version

Multi-device school system (HTTPS). Shared data for all phones.

## Login
- admin / 1234 (change after first login)

## Features
- Master roster tab
- Upload tab (Students, Staff, Timetable, Attendance, Marks, Fees, Library)
- Attendance daily / weekly / monthly reports
- Report cards (2-page, EN / Amharic / Afaan Oromoo)
- Marks components, timetable, fees, library
- Fingerprint helpers (Chrome + HTTPS)

## Deploy Railway
1. Push this folder to GitHub repo `naleti-academy`
2. railway.app → New Project → Deploy from GitHub
3. Settings → Networking → Generate Domain
4. Open https://your-app.up.railway.app in Chrome

## Deploy Replit
1. replit.com → Import from GitHub (or upload these files)
2. Run: npm install && npm start
3. Open the Replit https link

## Local
npm install && npm start
→ http://localhost:3000
